플랫폼
Windows PC · x64
지원 환경
Windows 10 22H2(빌드 19045) 이상 · Windows 11 / x64 PC
문서 형식
.adq 문서 Word·한글·PDF 변환 미지원

Microsoft Store

Store에 등록된 최소 OS는 Windows 10 빌드 19045.0 이상입니다. x64 PC와 WebView2 Runtime이 필요하며, 설치 전 Store의 최신 요구 사항을 확인하세요.

설치와 저장, 먼저 확인하세요

Windows Free와 Pro

Windows Free와 Pro는 Microsoft Store에서 별도 앱으로 제공합니다.

가격과 편집 한도 비교

저장 위치

동기화되지 않는 로컬 고정 NTFS 드라이브의 폴더를 사용하세요. OneDrive·네트워크 공유·USB 등 이동식 드라이브는 현재 저장 대상으로 지원하지 않습니다.

저장 위치 선택하기

WebView2 Runtime

편집 화면에 Microsoft Edge WebView2 Evergreen Runtime이 필요합니다. 설치·복구 안내를 확인하세요.

설치 조건 확인하기

문서는 .adq 형식으로 저장합니다. Word·한글·PDF 가져오기·내보내기는 현재 제공하지 않습니다.
