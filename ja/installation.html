インストールとスタート

Windows公開版のインストール

Windows Free・Proのインストール条件と保存先をご確認ください。

1. インストール先と動作環境

Windows用のFreeとProはMicrosoft Storeから個別にインストールできます。無料で始めるか、Pro機能をお試しください。

公式のインストール先は ダウンロード案内でご確認ください。

現在のStoreパッケージはWindows x64 PC用です。登録上の最小OSはWindows 10ビルド19045.0以降で、Windows 11でも使用できます。編集画面にはWebView2 Evergreen Runtimeが必要です。現在の公開ダウンロードはWindows x64用です。AndroidはGoogle Play公開を準備しています。

アプリが実行できるかどうかと、OS自体のセキュリティサポート状況は分けてご確認ください。

Microsoft Storeからインストール

  1. FreeとProを比較し、希望するエディションの公式Storeボタンを選択します。
  2. アプリ名と発行元ZINNIASHARKを確認します。Freeは無料でインストールでき、Proは30日間体験または買い切りを選べます。
  3. Storeのインストール案内に従います。FreeとProは別々のアプリです。
  4. インストールが完了したら、スタートメニューからZinniaShark Noteを起動します。
  5. 新しい文書を作り、Ctrl+Sでローカルの.adqファイルに保存してみましょう。
Freeを入手 Proを30日間無料体験

インストール・更新・Proの体験と購入には、Storeの通信・アカウント条件が適用される場合があります。インストールするバージョンは各Store製品ページでご確認ください。

2. WebView2 Evergreen Runtime

Microsoft EdgeブラウザーとWebView2 Runtimeは別の構成要素です。編集画面の実行にはRuntimeが必要です。

  1. Runtimeが見つからないという案内が出る、または編集画面が開かない場合は、作業を保存してアプリを終了します。
  2. Microsoft公式WebView2ダウンロードページでEvergreen Runtimeを選びます。オンラインではBootstrapper、オフラインではx64 Standalone Installerを利用できます。
  3. インストール後にアプリを再起動します。会社が管理するPCでは組織のインストールポリシーをご確認ください。
  4. 問題が続く場合は、エラーメッセージ・アプリとWindowsのバージョンを サポート窓口にお知らせください。

最初にアプリの削除や初期化を行わないでください。内部の作業データが削除される可能性があります。

3. 保存フォルダーを選ぶ

同期されていないローカル固定NTFSドライブの通常のフォルダーを使用してください。例えば固定C:ドライブがNTFSで同期対象でなければ、書き込み権限のある個人の作業フォルダーを選べます。

ドキュメントやデスクトップもOneDriveに接続されている場合があるため、実際のパスをご確認ください。OneDriveなどの同期フォルダー、ネットワーク共有、USBなどのリムーバブルストレージは保存先として非対応です。ファイルシステムはエクスプローラーのドライブのプロパティで確認できます。

インストールフォルダーや管理者権限が必要なシステムフォルダーには保存しないでください。別の場所にバックアップするには、まず対応フォルダーに保存してファイルを閉じ、エクスプローラーでコピーしてください。

4. はじめての文書を作る

  1. 新しい文書を作成し、本文を入力します。
  2. 見出しスタイルを適用し、目次から移動してみましょう。
  3. Ctrl+Sで対応フォルダーに.adqファイルを保存します。
  4. 文書を閉じ、Ctrl+Oで再度開いて内容を確認します。

画像・音声・動画の使い方は 使い方をご確認ください。

5. 更新・削除の前に

開いている文書と未保存の作業を必要な外部.adqファイルに保存し、別途バックアップしてから終了してください。Store版の更新はMicrosoft Storeで確認します。

現在のアプリは作業再開と定期的な復元用コピーの記録を提供していません。削除・初期化の前に、旧版の作業が残っていれば書き出して外部の文書コピーを確認してください。再インストールで未保存の作業は戻りません。

メジャーバージョンが変わるときは、 サポート・アップグレードポリシーの草案 (韓国語ページ)と該当バージョンの変更案内を先にご確認ください。
