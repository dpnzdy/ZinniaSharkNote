01 / はじめに

はじめての文書を作る

短い一文で十分です。資料や説明を収める文書から始めましょう。

  1. 01

    新しい文書を作る

    アプリを起動して新しい文書を作り、記録したいテーマと最初の一文を書いてみましょう。

  2. 02

    見出しで全体の流れをつくる

    段落スタイルから見出しを選んでください。見出しは目次に表示され、文書内を移動する目印になります。

  3. 03

    自分のファイルとして保存

    Ctrl + Sで保存し、名前と場所を決めてください。ローカル固定NTFSドライブの通常のフォルダーを使用してください。

まずはサンプル文書で使い心地を確かめましょう。 (韓国語ページ)
02 / 書く・整理する

読みやすく直しやすい構成に

見出し1〜6で内容を分け、表・リスト・引用・コードブロックで資料に合った整理ができます。大切な言葉には太字・斜体・下線・文字色を使えます。

見出しと目次見出しを選んで目的の場所へ移動します。
表とリスト比較する内容や作業手順を整理します。
書式とブロック引用・コード・文字書式で流れをつくります。
検索・置換繰り返し使う表現を探して修正します。

実際にタブを切り替えると前のタブの元に戻す履歴が初期化され、アプリの再起動時も最初からになります。

03 / 資料を添える

資料と説明を一緒に収める

挿入機能でメディアを追加するか、エクスプローラーから対応ファイルを文書へドラッグしてください。挿入した資料は.adqファイルに含まれます。

画像PNG · JPEG · GIF

サイズ・配置・回転・反転を調整し、説明を添えましょう。画面上の表示調整と元の素材は区別されます。

オーディオMP3

文書内で再生し、大切な表現や再確認したい箇所を記録しましょう。

ビデオMP4

場面を見ながら、気づいたことや浮かんだ思いを本文に記録しましょう。

対応形式でもコーデック・ファイルの状態・再生環境によって動作が異なる場合があります。音声認識・自動録音・動画編集機能は提供していません。

04 / 保存して開く

ファイルの保存と再オープン

変更内容はCtrl+Sで.adqファイルに保存します。

ファイル保存

Ctrl + S

現在の変更を元の.adqファイルに反映します。新しい文書では保存先と名前を決め、別名保存で個別のコピーを作れます。

再度開く

保存した.adqファイルを選択

通常の起動では空の文書から始まります。「ファイルを開く」または「最近使った文書」でディスクに保存したファイルを開いてください。最近使った文書は未保存の作業を復元しません。

現在のWindowsアプリは作業再開と定期的な復元用コピーの記録を提供していません。強制終了・停電では最後のファイル保存以降の変更を失う場合があります。

終了するとき

変更した文書ごとに保存・破棄・キャンセルを選びます。保存は変更をファイルに反映し、破棄は最後の保存以降の変更を捨て、キャンセルは編集画面に戻ります。複数の文書をすべて保存して終了することもできます。保存に失敗した場合は該当文書を確認して再度保存してください。

次の手順で確認しましょう

  1. 新しい文書を作り、内容を入力します。
  2. Ctrl+Sで.adqファイルの名前と保存先を決めます。
  3. 文書を閉じ、保存したファイルを再度開きます。
  4. 追加編集した後は、再びCtrl+Sで保存します。

旧バージョンの作業を書き出す

以前のバージョンの作業文書や復元用コピーが残っている場合は、「ファイル → 以前のバージョンの文書をエクスポート」で新しい.adqファイルに書き出せます。現在の作業を自動保持する機能ではありません。重要な文書は別のコピーでバックアップし、削除・初期化の前に書き出したファイルをご確認ください。

05 / 文書を保護

必要な文書にパスワードを設定

文書ごとにパスワードを設定・変更・解除できます。暗号化した文書はタイトルバーとタブの鍵アイコンで保存状態をご確認ください。

文書内容と埋め込み素材を一緒に暗号化します。

ADQ2の暗号化にはArgon2idによる鍵導出とAES-256-GCMを使用します。暗号化した文書を再度開く際はパスワードを入力します。

初めての場合は練習用のコピーでパスワード設定と再オープンを試してください。忘れると文書の暗号を解除できないため、安全に保管してください。

06 / 自分らしい流れに

自分に合った作業環境

  • よく使うツールをツールバーに表示し、順序を調整しましょう。
  • 使い慣れた操作に合わせてショートカットを設定しましょう。
  • 文書の表示幅と目次の幅を調整しましょう。
  • 目次の境界をドラッグして、読みやすい空間をつくりましょう。
Ctrl + S 保存Ctrl + Tab 文書タブを切り替えF6 主要な領域を移動
