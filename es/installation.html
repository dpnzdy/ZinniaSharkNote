INSTALAR Y EMPEZAR

Instalar la aplicación para Windows

Consulta los requisitos y las ubicaciones de guardado de Windows Free y Pro.

1. Origen de descarga y requisitos

Free y Pro para Windows son aplicaciones independientes en Microsoft Store. Empieza gratis o prueba las funciones Pro.

Consulta la fuente de instalación oficial en la guía de descarga.

El paquete actual de Store es para PC Windows x64. El sistema mínimo indicado es Windows 10 compilación 19045.0; también es compatible con Windows 11. El editor requiere WebView2 Evergreen Runtime. La descarga pública actual es para Windows x64. Se está preparando la publicación de Android en Google Play.

Comprueba por separado si la aplicación puede ejecutarse y si el sistema operativo sigue recibiendo soporte de seguridad.

Instalar desde Microsoft Store

  1. Compara Free y Pro y selecciona el botón oficial de Store de la edición que prefieras.
  2. Comprueba el nombre de la aplicación y el editor ZINNIASHARK. Instala Free gratis o elige una prueba de 30 días o un pago único para Pro.
  3. Sigue las instrucciones de instalación de Store. Free y Pro son aplicaciones independientes.
  4. Tras la instalación, abre ZinniaShark Note desde el menú Inicio.
  5. Crea un documento y pulsa Ctrl+S para guardarlo como archivo .adq local.
Descargar Free Probar Pro gratis durante 30 días

La instalación, las actualizaciones, la prueba Pro y las compras pueden estar sujetas a requisitos de red y cuenta de Store. Consulta la versión disponible en la página de cada producto.

2. WebView2 Evergreen Runtime

Microsoft Edge y WebView2 Runtime son componentes independientes. El editor necesita Runtime.

  1. Si la aplicación indica que falta Runtime o no abre el editor, guarda tu trabajo y ciérrala.
  2. la página oficial de descarga de WebView2 de Microsoft ofrece Evergreen Runtime. Usa Bootstrapper para instalar en línea o x64 Standalone Installer para instalar sin conexión.
  3. Reinicia la aplicación después de instalar. En un PC gestionado por tu empresa, consulta su política de instalación.
  4. Si el problema persiste, envía el mensaje de error y las versiones de la aplicación y de Windows a soporte.

No desinstales ni restablezcas la aplicación como primer paso. Podrían borrarse los datos de trabajo internos.

3. Elegir carpeta de guardado

Usa una carpeta normal no sincronizada de una unidad fija local NTFS. Por ejemplo, si C: es una unidad fija NTFS sin sincronización, elige una carpeta de trabajo personal con permiso de escritura.

Documentos y Escritorio pueden estar vinculados a OneDrive; comprueba sus rutas reales. No se admiten carpetas sincronizadas como OneDrive, recursos de red ni almacenamiento extraíble como USB como destino de guardado. Consulta el sistema de archivos en las propiedades de la unidad del Explorador.

No guardes documentos en la carpeta de instalación ni en carpetas del sistema que exijan permisos de administrador. Para hacer una copia en otro lugar, guarda primero en una carpeta compatible, cierra el archivo y cópialo con el Explorador.

4. Crear el primer documento

  1. Crea un documento y escribe texto.
  2. Aplica un estilo de título y navega por el índice.
  3. Pulsa Ctrl+S para guardar el archivo .adq en una carpeta compatible.
  4. Cierra el documento, ábrelo de nuevo con Ctrl+O y comprueba su contenido.

Para imágenes, audio y vídeo, consulta la Guía de uso.

5. Antes de actualizar o desinstalar

Guarda los documentos abiertos y el trabajo pendiente en archivos .adq externos, crea copias de seguridad y cierra la aplicación. Busca actualizaciones de la edición Store en Microsoft Store.

La aplicación actual no restaura sesiones ni crea copias periódicas de recuperación. Antes de desinstalar o restablecer, exporta el trabajo que quede de versiones anteriores y comprueba las copias externas. Reinstalar no recupera el trabajo sin guardar.

Antes de cambiar de versión principal, consulta el borrador de la política de soporte y actualización (Página en coreano) y las notas de cambios de esa versión.
