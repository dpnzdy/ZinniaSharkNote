INSTALLIEREN & STARTEN

Windows-App installieren

Prüfen Sie die Voraussetzungen und Speicherorte für Windows Free und Pro.

1. Bezugsquelle und Systemanforderungen

Free und Pro für Windows sind separate Apps im Microsoft Store. Starten Sie kostenlos oder testen Sie die Pro-Funktionen.

Den offiziellen Installationsweg finden Sie unter Download-Anleitung.

Das aktuelle Store-Paket ist für Windows-x64-PCs. Als Mindestversion ist Windows 10 Build 19045.0 angegeben; Windows 11 wird ebenfalls unterstützt. Der Editor benötigt WebView2 Evergreen Runtime. Der öffentliche Download ist derzeit für Windows x64 verfügbar. Die Android-Veröffentlichung bei Google Play wird vorbereitet.

Prüfen Sie getrennt, ob die App ausführbar ist und ob das Betriebssystem noch Sicherheitsunterstützung erhält.

Aus dem Microsoft Store installieren

  1. Vergleichen Sie Free und Pro und wählen Sie die offizielle Store-Schaltfläche der gewünschten Edition.
  2. Prüfen Sie den App-Namen und den Herausgeber ZINNIASHARK. Free ist kostenlos; bei Pro wählen Sie eine 30-Tage-Testphase oder einen Einmalkauf.
  3. Folgen Sie den Installationshinweisen des Stores. Free und Pro sind separate Apps.
  4. Starten Sie ZinniaShark Note nach der Installation über das Startmenü.
  5. Erstellen Sie ein Dokument und speichern Sie es mit Strg+S als lokale .adq-Datei.
Free herunterladen Pro 30 Tage kostenlos testen

Für Installation, Updates, Pro-Test und Kauf können Netzwerk- und Kontovoraussetzungen des Stores gelten. Die angebotene Version finden Sie auf der jeweiligen Store-Produktseite.

2. WebView2 Evergreen Runtime

Microsoft Edge und WebView2 Runtime sind separate Komponenten. Für den Editor ist die Runtime erforderlich.

  1. Wenn die App eine fehlende Runtime meldet oder der Editor nicht startet, speichern Sie Ihre Arbeit und beenden Sie die App.
  2. die offizielle WebView2-Downloadseite von Microsoft bietet Evergreen Runtime an. Nutzen Sie online den Bootstrapper oder offline den x64 Standalone Installer.
  3. Starten Sie die App nach der Installation erneut. Prüfen Sie bei verwalteten Firmen-PCs die Installationsrichtlinien Ihrer Organisation.
  4. Bei anhaltenden Problemen senden Sie Fehlermeldung, App-Version und Windows-Version an den Support.

Deinstallieren oder setzen Sie die App nicht als ersten Schritt zurück. Interne Arbeitsdaten können dabei gelöscht werden.

3. Speicherordner auswählen

Verwenden Sie einen normalen, nicht synchronisierten Ordner auf einem lokalen festen NTFS-Laufwerk. Ist etwa Ihr festes Laufwerk C: mit NTFS formatiert und nicht synchronisiert, können Sie einen beschreibbaren persönlichen Arbeitsordner wählen.

Auch Dokumente und Desktop können mit OneDrive verbunden sein; prüfen Sie den tatsächlichen Pfad. Synchronisierte Ordner wie OneDrive, Netzwerkfreigaben und Wechseldatenträger wie USB werden nicht als Speicherziel unterstützt. Das Dateisystem sehen Sie in den Laufwerkseigenschaften im Explorer.

Speichern Sie Dokumente nicht im Installationsordner oder in Systemordnern mit Administratorrechten. Speichern Sie für ein Backup zunächst in einem unterstützten Ordner, schließen Sie die Datei und kopieren Sie sie dann im Explorer.

4. Erstes Dokument erstellen

  1. Erstellen Sie ein Dokument und geben Sie Text ein.
  2. Wenden Sie einen Überschriftenstil an und navigieren Sie über die Gliederung.
  3. Speichern Sie mit Strg+S eine .adq-Datei in einem unterstützten Ordner.
  4. Schließen Sie das Dokument, öffnen Sie es mit Strg+O erneut und prüfen Sie den Inhalt.

Hinweise zu Bildern, Audio und Videos finden Sie in der Anleitung.

5. Vor Update oder Deinstallation

Speichern Sie offene Dokumente und ungespeicherte Arbeit als externe .adq-Dateien, erstellen Sie separate Sicherungen und beenden Sie die App. Updates der Store-Version finden Sie im Microsoft Store.

Die aktuelle App stellt frühere Sitzungen nicht wieder her und erstellt keine regelmäßigen Wiederherstellungskopien. Exportieren Sie vor Deinstallation oder Zurücksetzen verbliebene Arbeit älterer Versionen und prüfen Sie die externen Dokumentkopien. Eine Neuinstallation stellt ungespeicherte Arbeit nicht wieder her.

Prüfen Sie vor einem Wechsel der Hauptversion den Entwurf der Support- und Upgrade-Richtlinie und die Änderungshinweise der betreffenden Version.
