FREQUENTLY ASKED QUESTIONS

자주 묻는 질문

01어떤 Windows 환경에서 사용할 수 있나요?

현재 Store 패키지는 Windows x64 PC용입니다. Store에 등록된 최소 OS는 Windows 10 빌드 19045.0 이상이며 Windows 11에서도 사용할 수 있습니다. 편집 화면에는 WebView2 Evergreen Runtime이 필요합니다. 현재 공개 다운로드는 Windows x64용입니다. Android는 Google Play 공개를 준비하고 있습니다.

02Windows용 ZinniaShark Note는 어디에서 다운로드하나요?

Microsoft Store에서 ZinniaShark Note(Free)와 ZinniaShark Note Pro를 각각 설치할 수 있습니다. 무료로 시작하려면 Free를, Pro 기능을 30일 동안 체험하려면 Pro를 선택하세요.

03Free와 Pro는 무엇이 다른가요?

Free는 무료로 사용할 수 있으며, 문서 한 개에 최상위 블록을 최대 500개, 미디어를 최대 15개까지 추가할 수 있습니다.

Pro는 30일 무료 체험을 제공하며, 일회성 구매 가격은 USD $15.99입니다. 체험 기간과 구매 후에는 이 두 개수 제한이 해제됩니다. 지역별 가격은 Microsoft Store에서 확인하세요.

04인터넷 연결 없이 문서를 작성할 수 있나요?

클라우드 업로드를 전제로 하지 않는 로컬 파일 중심 앱입니다. 문서는 내 PC의 파일로 열고 편집·저장합니다. Store 설치·업데이트 등 배포 서비스의 이용에는 네트워크가 필요할 수 있습니다.

05Word·한글·PDF 파일도 열거나 저장할 수 있나요?

현재 지원하는 문서 형식은 ADQ2/논리 v3의 .adq 파일입니다. DOCX·HWP/HWPX·PDF·Markdown 가져오기·내보내기는 현재 지원 범위에 포함되지 않습니다.

06이미지·오디오·영상은 문서와 함께 저장되나요?

PNG·JPEG·GIF 이미지, MP3 오디오, MP4 비디오를 삽입할 수 있습니다. 삽입한 미디어는 .adq 파일 안에 포함됩니다. 다른 PC에서는 호환되는 ZinniaShark Note와 해당 미디어를 재생할 수 있는 환경이 필요합니다.

07작업 내용은 어떻게 저장하나요?

Ctrl+S로 변경 내용을 .adq 파일에 저장하세요. 나중에 편집을 계속하려면 저장한 파일을 다시 열면 됩니다. 현재 Windows 앱은 작업 이어하기와 주기적 복구 사본 기록을 제공하지 않습니다. 종료 전에 필요한 변경 내용을 파일에 저장해주세요.

08앱을 종료하거나 구버전 작업을 가져오려면 어떻게 하나요?

종료할 때 변경된 문서마다 저장·버리기·취소를 선택합니다. 구버전 작업이나 복구 사본이 남아 있으면 파일 → 이전 버전 문서 내보내기에서 새 .adq 파일로 내보낼 수 있습니다. 파일 저장과 다시 열기를 확인하세요.

09Android는 어디에서 설치할 수 있나요?

Android는 Google Play 공개를 준비하고 있습니다. 개발판에서 구현한 기능과 검증 범위를 확인할 수 있습니다.

10다른 기기에서도 문서를 열 수 있나요?

저장한 .adq 파일을 다른 PC로 옮겨 호환되는 ZinniaShark Note에서 열 수 있습니다. 이동 전에 변경 내용을 저장하세요. 클라우드 동기화와 기기 간 자동 작업 재개는 제공하지 않습니다.

11문서 비밀번호를 잊었어요. 어떻게 하나요?

문서 내용과 포함 자산을 비밀번호로 암호화합니다. 비밀번호를 잊으면 문서의 암호를 해제할 수 없습니다. 문서에 설정한 비밀번호를 안전하게 보관해주세요.

12문서 용량이나 열린 문서 수에 제한이 있나요?

문서·자산 크기, 열린 문서 수와 메모리·표시 자원에 한도가 적용됩니다. 파일 크기만으로 열기 가능 여부를 판단할 수 없으며, 같은 크기의 모든 문서에서 동일한 성능을 보장하지 않습니다. 용량 제한 안내가 나오면 작업을 저장하고 불필요한 탭을 닫은 뒤 안내 내용을 확인해주세요.

13미디어가 재생되지 않으면 어떻게 하나요?

지원 형식과 문서·자산의 용량을 확인하고, 원본 파일이 Windows에서 정상적으로 재생되는지 살펴보세요. 문제가 계속되면 앱 버전, Windows 버전, 파일 형식과 오류 메시지를 이메일로 알려주세요.

14탭을 바꾸거나 앱을 재시작한 뒤 실행 취소가 되지 않아요.

현재 앱은 실제 탭 전환에 성공하면 이전 탭의 Undo/Redo 기록을 초기화합니다. 앱을 재시작할 때도 실행 취소 기록은 새로 시작합니다. 중요한 변경 전에는 사본을 저장해두세요.
