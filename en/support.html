FREQUENTLY ASKED QUESTIONS

Frequently asked questions

01Which Windows systems are supported?

The current Store package is for Windows x64 PCs. The minimum listed OS is Windows 10 build 19045.0; Windows 11 is also supported. The editor requires WebView2 Evergreen Runtime. The public download is currently for Windows x64. An Android release on Google Play is in preparation.

02Where can I download ZinniaShark Note for Windows?

You can install ZinniaShark Note (Free) and ZinniaShark Note Pro separately from Microsoft Store. Choose Free to start at no cost, or Pro to try its features for 30 days.

Get Free Try Pro free for 30 days
View download and installation help
03What is the difference between Free and Pro?

Free is available at no cost and lets you add up to 500 top-level blocks and 15 media items per document.

Pro offers a 30-day free trial and a one-time purchase for USD $15.99. These two count limits are removed during the trial and after purchase. Check Microsoft Store for regional pricing.

Compare Windows editions →
04Can I write documents offline?

The app works with local files and does not require cloud uploads. Open, edit and save documents on your PC. Distribution services such as Store installation and updates may require a network connection.

05Can I open or save Word, HWP or PDF files?

The supported format is .adq (ADQ2/logical v3). Import and export of DOCX, HWP/HWPX, PDF and Markdown are not currently supported.

06Are images, audio and video saved with the document?

You can insert PNG, JPEG and GIF images, MP3 audio and MP4 video. Inserted media is embedded in the .adq file. Another PC needs a compatible version of ZinniaShark Note and an environment capable of playing that media.

07How do I save my work?

Press Ctrl+S to save changes to the .adq file. To continue editing later, reopen the saved file. The current Windows app does not restore previous sessions or create periodic recovery copies. Save the changes you need before closing.

How to save files (Korean page)
08How do I close the app or retrieve work from older versions?

On exit, choose Save, Discard or Cancel for each modified document. If work or recovery copies from older versions remain, use File → Export documents from older versions to export them as new .adq files. See saving files and reopening them (Korean page).

09Where can I install the Android app?

An Android release on Google Play is in preparation. See features implemented and checks performed in the development build (Korean page).

10Can I open documents on another device?

You can move a saved .adq file to another PC and open it with a compatible version of ZinniaShark Note. Save your changes before transferring it. Cloud synchronization and automatic session continuation across devices are not provided.

11I forgot my document password. What can I do?

The document content and embedded assets are encrypted with the password. If you forget it, you cannot decrypt the document. Keep your document password safe.

12Are there limits on document size or open documents?

Limits apply to document and asset sizes, open document counts, memory and display resources. File size alone does not determine whether a document can be opened, and equal-sized documents may perform differently. If a limit warning appears, save your work, close unneeded tabs and follow the guidance.

13What if media will not play?

Check the supported formats and document/asset sizes, and whether the original file plays correctly in Windows. If the problem continues, email us the app version, Windows version, file format and error message.

14Undo stops working after switching tabs or restarting.

The app resets the previous tab’s Undo/Redo history after a successful tab switch. Undo history also starts fresh when the app restarts. Save a copy before important changes.
