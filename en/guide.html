01 / GET STARTED

Create your first document

One short sentence is enough. Start a document for your materials and explanations.

  1. 01

    Create a document

    Launch the app, create a document and write your topic and opening sentence.

  2. 02

    Structure it with headings

    Choose a heading from the paragraph styles. Headings appear in the outline to help you navigate the document.

  3. 03

    Save it as your own file

    Ctrl + S saves the file; choose its name and location. Use a regular folder on a local fixed NTFS drive.

02 / WRITE & ORGANIZE

Make your writing easy to read and edit

Organize content with heading levels 1–6, tables, lists, quotes and code blocks. Emphasize important words with bold, italic, underline or text color.

03 / ADD YOUR MATERIALS

Keep media and explanations together

Use Insert to add media or drag supported files from File Explorer into the document. Inserted materials are embedded in the .adq file.

ImagesPNG · JPEG · GIF

Adjust size, alignment, rotation and flipping, then add a description. Display adjustments are separate from the original asset.

AudioMP3

Play it within the document and note important phrases or points to revisit.

VideoMP4

Watch the scene and record your observations and ideas in the text.

Even supported formats may behave differently depending on codecs, file condition and playback environment. Speech recognition, automatic recording and video editing are not provided.

04 / SAVE & OPEN

Saving and reopening files

Save changes to the .adq file with Ctrl+S.

File saving

Ctrl + S

Write your current changes to the original .adq file. For a new document, choose a name and location; Save As creates a separate copy.

Reopen

Select a saved .adq file

The app normally starts with a blank document. Use Open or Recent documents to reopen a file saved on disk. Recent documents does not restore unsaved work.

The current Windows app does not restore previous sessions or create periodic recovery copies. A forced exit or power failure may lose changes since the last file save.

When closing the app

For each modified document, choose Save, Discard or Cancel. Save writes changes to the file; Discard removes changes since the last save; Cancel returns to editing. You can save all documents before exiting. If saving fails, check the affected document and try again.

Try this

  1. Create a document and enter some content.
  2. Press Ctrl+S and choose the .adq file name and save location.
  3. Close the document and reopen the saved file.
  4. After further edits, save again with Ctrl+S.

Export work from older versions

If work documents or recovery copies from older versions remain, use File → Export documents from older versions to create new .adq files. This does not automatically preserve current work. Back up important documents separately and check exported files before uninstalling or resetting the app.

05 / PROTECT YOUR DOCUMENT

Set passwords for documents that need protection

You can set, change or remove a password for each document. For encrypted documents, check the lock icons in the title bar and tab for their saved state.

Encrypt document content and embedded assets together.

ADQ2 encryption uses Argon2id key derivation and AES-256-GCM. Enter the password when reopening an encrypted document.

If this is your first time, try setting a password and reopening a practice copy. Keep the password safe: a forgotten password prevents decryption.
