TROUBLESHOOTING

When something goes wrong,
check one thing at a time.

Troubleshooting for the current Windows Free and Pro apps. Distinguish saved files from work exported from older versions.

The app will not start or the editor is blank

  1. Check Windows x64 compatibility and the requirements of your app release.
  2. If WebView2 is missing, install Evergreen Runtime using the installation guide.
  3. Note the error message and restart the app. Do not reset or uninstall before saving your work to external files.

WebView2 installation help

I cannot save a document

  1. Check that the actual save path is a non-synchronized folder on a local fixed NTFS drive.
  2. Check folder write permissions and free disk space. Avoid OneDrive, network shares and removable drives.
  3. Try Save As in a supported folder without overwriting the original. Record the error message and steps taken.

An ADQ document will not open

  1. The supported format is ADQ2 container/logical v3. Older .adq files may be unsupported even with the same extension.
  2. Check the error message and file size. Do not change the extension or modify the original file directly.
  3. Preserve important originals and check a copy. Complete recovery of damaged files is not guaranteed.

Media will not play

  1. Check that the media is a supported PNG, JPEG or GIF image, MP3 audio or MP4 video.
  2. Check whether the original audio or video plays in Windows and whether the volume and output device are correct.
  3. Playback may differ even for the same format due to codecs, damage or resource limits. Report the format, size and error.

I forgot my document password

  1. Check your keyboard input language and Caps Lock.
  2. If you forget the document password, the file cannot be decrypted. Check where you stored the password and any separate copies.
  3. The provider does not guarantee decryption or resetting a lost password. Do not send document passwords by support email.

Saved content or Undo is not what I expected

  1. The current Windows app does not restore previous sessions or create periodic recovery copies. Check that you opened the .adq file saved with Ctrl+S.
  2. A forced exit or power failure may lose changes since the last file save. If older-version work remains, use File → Export documents from older versions.
  3. After an actual tab switch, the previous tab’s Undo/Redo history resets. Undo history also starts fresh when the app restarts.

Include this when contacting support

Send the app version, Windows version, steps to reproduce and error message through the support page. Provide minimal reproduction information with sensitive data removed, rather than original documents, passwords or personal information. App privacy policy (Korean page) is also available.
