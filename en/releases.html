Current Windows Free and Pro

Free and Pro for Windows are separate apps on Microsoft Store. Start for free or try Pro features.

Free is available at no cost and lets you add up to 500 top-level blocks and 15 media items per document.

Pro offers a 30-day free trial and a one-time purchase for USD $15.99. These two count limits are removed during the trial and after purchase. Check Microsoft Store for regional pricing.

The current app saves to a file with Ctrl+S. On exit, choose Save, Discard or Cancel for each modified document. Previous sessions are not restored and periodic recovery copies are not created.

Requirements and known limitations

The current Store package is for Windows x64 PCs. The minimum listed OS is Windows 10 build 19045.0; Windows 11 is also supported. The editor requires WebView2 Evergreen Runtime. The public download is currently for Windows x64. An Android release on Google Play is in preparation.

  • Supported .adq files use the ADQ2 container/logical v3 format. Check your version’s guidance for supported document formats.
  • Save in a non-synchronized folder on a local fixed NTFS drive.
  • Cloud synchronization and automatic session continuation across devices are not provided.
  • Undo history resets after an actual tab switch or app restart.
  • Media playback depends on supported formats, codecs, file condition and the runtime environment.

Updates and support

Check each edition’s Microsoft Store page for updates and the current release version. Before updating, save changes as .adq files and keep separate copies. If older work or recovery copies remain, export documents from older versions before uninstalling or resetting.
