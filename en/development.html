Saving and reopening Windows files

The app normally starts with a blank document. Use Open or Recent documents to open an .adq file saved on disk. The current app does not restore previous sessions or create periodic recovery copies.

  • Save to file · Press Ctrl+S to write changes to the .adq file. Save before closing the file.
  • Exit · For each modified document, choose Save, Discard or Cancel. If saving fails, check the document and try again.
  • Older-version work · Remaining work documents or recovery copies can be exported as new .adq files using File → Export documents from older versions. This does not automatically preserve the current document.

A forced exit or power failure may lose changes since the last file save. See Saving and reopening files.

Windows Free and Pro

Free is available at no cost and lets you add up to 500 top-level blocks and 15 media items per document.

Pro offers a 30-day free trial and a one-time purchase for USD $15.99. These two count limits are removed during the trial and after purchase. Check Microsoft Store for regional pricing.

Windows Free and Pro are installed as separate Microsoft Store apps. Removing Pro’s block and media count limits does not remove technical limits on file size, structure or memory.

Android development status

Release on Google Play is in preparation. The development build edits one document at a time and supports text, tables, PNG/JPEG/GIF images, MP3/MP4 media and document passwords. Open and save .adq files using the system file picker.

When saving an existing file, the app checks for external changes, creates a pre-save copy and rereads the result. Periodic autosave is off by default. Choose a file location on the first save. Pre-save copies do not include unsaved edits; a forced exit may lose changes since the last save.

Some saving and editing flows were checked by automated tests on a physical device. The latest muted autoplay was checked for decoder output and video switching in an emulator. Hands-on input, listening and TalkBack evaluation on a physical device remain outstanding.

Android app privacy policy

Media insertion limits

These per-file limits apply when inserting new media in the Windows and Android development builds.

  • PNG/JPEG/GIF images: 8 MiB
  • MP3 audio: 16 MiB
  • MP4 video: 32 MiB

The combined media assets referenced by a document are limited to 128 MiB; the document container budget for new insertions is 256 MiB. Existing assets in supported documents are preserved when opening, editing and saving.
