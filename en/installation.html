INSTALL & START

Install the Windows app

Check the requirements and save locations for Windows Free and Pro.

1. Download source and requirements

Free and Pro for Windows are separate apps on Microsoft Store. Start for free or try Pro features.

For the official installation source, see download instructions.

The current Store package is for Windows x64 PCs. The minimum listed OS is Windows 10 build 19045.0; Windows 11 is also supported. The editor requires WebView2 Evergreen Runtime. The public download is currently for Windows x64. An Android release on Google Play is in preparation.

Check whether the app can run separately from whether the operating system still receives security support.

Install from Microsoft Store

  1. Compare Free and Pro and select the official Store button for your preferred edition.
  2. Check the app name and publisher ZINNIASHARK. Install Free at no cost, or choose a 30-day trial or one-time purchase for Pro.
  3. Follow the Store installation instructions. Free and Pro are separate apps.
  4. After installation, launch ZinniaShark Note from the Start menu.
  5. Create a document and press Ctrl+S to save it as a local .adq file.
Get Free Try Pro free for 30 days

Store network and account requirements may apply to installation, updates, Pro trials and purchases. Check each product’s Store page for its installation version.

2. WebView2 Evergreen Runtime

Microsoft Edge and WebView2 Runtime are separate components. The editor requires the Runtime.

  1. If the app reports a missing Runtime or the editor does not open, save your work and close the app.
  2. Microsoft’s official WebView2 download page provides Evergreen Runtime. Use the Bootstrapper for online installation or the x64 Standalone Installer for offline installation.
  3. Restart the app after installation. On a managed work PC, check your organization’s installation policies.
  4. If the problem persists, send the error message, app version and Windows version to support.

Do not uninstall or reset the app first. Internal work data may be deleted.

3. Choose a save folder

Use a regular, non-synchronized folder on a local fixed NTFS drive. For example, if your fixed C: drive uses NTFS and is not synchronized, choose a personal work folder you can write to.

Documents and Desktop folders may be linked to OneDrive; check their actual paths. Synchronized folders such as OneDrive, network shares and removable storage such as USB drives are not supported save destinations. Check the file system in the drive properties in File Explorer.

Do not save documents in the installation folder or system folders requiring administrator rights. To back up elsewhere, first save in a supported folder, close the file, then copy it using File Explorer.

4. Create your first document

  1. Create a document and type some text.
  2. Apply a heading style and try navigating with the outline.
  3. Press Ctrl+S to save an .adq file in a supported folder.
  4. Close the document, reopen it with Ctrl+O and check its contents.

For images, audio and video, see the User guide.

5. Before updating or uninstalling

Save open documents and unsaved work as external .adq files, make separate backups, then close the app. Check Microsoft Store for updates to the Store edition.

The current app does not restore previous sessions or create periodic recovery copies. Before uninstalling or resetting, export any remaining older-version work and check the external document copies. Reinstalling will not restore unsaved work.

Before moving to a new major version, review the draft support and upgrade policy and the release information for that version.
