현재 Windows Free·Pro

Windows용 Free와 Pro를 각각 Microsoft Store에서 설치할 수 있습니다. 무료로 시작하거나 Pro 기능을 체험해보세요.

Free는 무료로 사용할 수 있으며, 문서 한 개에 최상위 블록을 최대 500개, 미디어를 최대 15개까지 추가할 수 있습니다.

Pro는 30일 무료 체험을 제공하며, 일회성 구매 가격은 USD $15.99입니다. 체험 기간과 구매 후에는 이 두 개수 제한이 해제됩니다. 지역별 가격은 Microsoft Store에서 확인하세요.

현재 앱은 Ctrl+S로 파일에 저장하며, 종료 시 변경된 문서마다 저장·버리기·취소를 선택합니다. 작업 이어하기와 주기적 복구 사본 기록은 제공하지 않습니다.

이전 공개 버전 1.0.2.0 — 변경 기록

2026년 11월 6일 · Microsoft Store · 당시 무료 Windows x64 앱

아래는 해당 버전의 과거 기록이며 현재 Free·Pro의 버전 번호나 기능 안내가 아닙니다. 최초 공개일은 2026년 11월 3일입니다.

  • Adequora Writer의 이름이 ZinniaShark Note로 변경되었습니다.
  • 앱 제목·안내·시작 메뉴 표시와 제품 소개를 새 이름으로 정리했습니다.
  • 기존 .adq 문서 형식, 패키지 식별자와 데이터 저장 위치를 유지합니다.

이전 1.0 버전에는 로컬 작업 이어하기가 있었으나 현재 Windows 앱에서는 제거되었습니다.

지원 환경과 알려진 제한

현재 Store 패키지는 Windows x64 PC용입니다. Store에 등록된 최소 OS는 Windows 10 빌드 19045.0 이상이며 Windows 11에서도 사용할 수 있습니다. 편집 화면에는 WebView2 Evergreen Runtime이 필요합니다. 현재 공개 다운로드는 Windows x64용입니다. Android는 Google Play 공개를 준비하고 있습니다.

  • .adq 중 ADQ2 컨테이너·논리 v3를 지원합니다. 문서 형식 지원은 사용하는 버전의 안내를 확인하세요.
  • 저장은 동기화되지 않는 로컬 고정 NTFS 폴더를 사용합니다.
  • 클라우드 동기화와 기기 간 자동 작업 재개는 제공하지 않습니다.
  • 실제 탭 전환 및 앱 재시작 시 실행 취소 기록이 초기화됩니다.
  • 미디어 재생은 지원 형식·코덱·파일 상태와 실행 환경에 영향을 받습니다.

업데이트와 지원 안내

각 에디션의 Microsoft Store 페이지에서 업데이트와 현재 배포 버전을 확인하세요. 업데이트 전 변경 내용을 .adq 파일로 저장하고 별도 사본을 보관하세요. 구버전 작업이나 복구 사본이 남아 있으면 제거·초기화 전에 이전 버전 문서 내보내기를 이용하세요.
