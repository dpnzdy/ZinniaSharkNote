INSTALLATION ET DÉMARRAGE

Installer l’application Windows

Vérifiez les prérequis et les emplacements d’enregistrement pour Windows Free et Pro.

1. Source de téléchargement et configuration

Free et Pro pour Windows sont deux applications distinctes sur le Microsoft Store. Commencez gratuitement ou essayez les fonctions Pro.

Pour la source d’installation officielle, consultez les instructions de téléchargement.

Le package actuel du Store est destiné aux PC Windows x64. Le système minimal indiqué est Windows 10 build 19045.0 ; Windows 11 est également pris en charge. L’éditeur nécessite WebView2 Evergreen Runtime. Le téléchargement public concerne actuellement Windows x64. La sortie Android sur Google Play est en préparation.

Distinguez la possibilité d’exécuter l’application du maintien du support de sécurité du système d’exploitation.

Installer depuis le Microsoft Store

  1. Comparez Free et Pro et sélectionnez le bouton officiel du Store pour l’édition souhaitée.
  2. Vérifiez le nom de l’application et l’éditeur ZINNIASHARK. Free s’installe gratuitement ; pour Pro, choisissez un essai de 30 jours ou un achat unique.
  3. Suivez les instructions d’installation du Store. Free et Pro sont deux applications distinctes.
  4. Après l’installation, lancez ZinniaShark Note depuis le menu Démarrer.
  5. Créez un document et appuyez sur Ctrl+S pour l’enregistrer dans un fichier .adq local.
Obtenir Free Essayer Pro gratuitement pendant 30 jours

L’installation, les mises à jour, l’essai Pro et les achats peuvent être soumis aux exigences de réseau et de compte du Store. Vérifiez la version proposée sur chaque fiche produit.

2. WebView2 Evergreen Runtime

Microsoft Edge et WebView2 Runtime sont deux composants distincts. L’éditeur nécessite le Runtime.

  1. Si l’application signale l’absence du Runtime ou si l’éditeur ne s’ouvre pas, enregistrez votre travail puis fermez l’application.
  2. la page officielle de téléchargement WebView2 de Microsoft propose Evergreen Runtime. Utilisez le Bootstrapper pour une installation en ligne ou le x64 Standalone Installer hors ligne.
  3. Relancez l’application après l’installation. Sur un PC professionnel géré, vérifiez les règles d’installation de votre organisation.
  4. Si le problème persiste, transmettez le message d’erreur et les versions de l’application et de Windows au service d’assistance.

Ne commencez pas par désinstaller ou réinitialiser l’application. Les données de travail internes risquent d’être supprimées.

3. Choisir un dossier d’enregistrement

Utilisez un dossier ordinaire non synchronisé sur un disque fixe local NTFS. Par exemple, si le disque fixe C: est en NTFS et non synchronisé, choisissez un dossier personnel accessible en écriture.

Les dossiers Documents et Bureau peuvent être liés à OneDrive ; vérifiez leurs chemins réels. Les dossiers synchronisés tels que OneDrive, les partages réseau et les supports amovibles comme les clés USB ne sont pas pris en charge comme destinations. Le système de fichiers figure dans les propriétés du lecteur dans l’Explorateur.

N’enregistrez pas les documents dans le dossier d’installation ou les dossiers système nécessitant des droits administrateur. Pour une sauvegarde ailleurs, enregistrez dans un dossier pris en charge, fermez le fichier, puis copiez-le avec l’Explorateur.

4. Créer votre premier document

  1. Créez un document et saisissez du texte.
  2. Appliquez un style de titre et essayez de naviguer avec le sommaire.
  3. Appuyez sur Ctrl+S pour enregistrer le fichier .adq dans un dossier pris en charge.
  4. Fermez le document, rouvrez-le avec Ctrl+O et vérifiez son contenu.

Pour les images, le son et les vidéos, consultez le Guide d’utilisation.

5. Avant une mise à jour ou désinstallation

Enregistrez documents ouverts et travail non enregistré dans des fichiers .adq externes, créez des sauvegardes séparées, puis fermez l’application. Les mises à jour de l’édition Store se trouvent sur le Microsoft Store.

L’application actuelle ne restaure pas les sessions et ne crée pas de copies de récupération périodiques. Avant de désinstaller ou réinitialiser, exportez le travail restant d’anciennes versions et vérifiez les copies externes. Une réinstallation ne restaure pas le travail non enregistré.

Avant de changer de version majeure, consultez le projet de politique de support et de mise à niveau et les notes de changement de la version concernée.
